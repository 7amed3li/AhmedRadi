# توثيق موقع مكتب أحمد راضي للاستشارات الهندسية

موقع إلكتروني مهني تم تطويره بالكامل باستخدام Next.js 16 (App Router) وTypeScript وTailwind CSS لمكتب المهندس أحمد راضي للاستشارات الهندسية والمساحية في المملكة العربية السعودية.

---

## الخصائص التقنية والهندسية

1. **التركيز على الجوال ومعدلات التحويل:**
   - شريط تفاعلي سفلي ثابت على الهواتف الذكية للاتصال الهاتفي والمحادثة الفورية.
   - روابط بروتوكول اتصال مباشر tel ورسائل واتساب مخصصة لكل خدمة.
   - استمارة طلب استشارة هندسية مبسطة مكونة من عمود واحد لسرعة التعبئة.

2. **الهوية البصرية:**
   - اعتماد الهوية الرسمية: كحلي داكن مع لمسات ذهبية مطفية، مستوحاة من شعار المكتب والمخططات الهندسية.
   - اعتماد صيغة WebP فائقة السرعة والخفة للشعار والأيقونات.
   - استخدام مكتبة Lucide React للأيقونات الاحترافية القياسية.

3. **12 خدمة بلدية ومساحية متخصصة:**
   - /services/building-license: إصدار رخصة بناء.
   - /services/land-fencing-license: إصدار رخصة تسوير أرض فضاء.
   - /services/renew-building-license: تجديد رخص البناء.
   - /services/modify-building-license: تعديل رخص البناء.
   - /services/occupancy-certificate: إصدار شهادة إتمام بناء أو شهادة إشغال.
   - /services/residential-to-commercial: تحويل رخصة من سكني إلى سكني تجاري.
   - /services/correct-building-status: تصحيح وضع المباني القائمة.
   - /services/cadastral-report: إصدار تقرير مساحي معتمد عبر بلدي.
   - /services/deed-update: تحديث الصكوك الورقية القديمة.
   - /services/civil-defense-services: خدمات واستشارات الدفاع المدني.
   - /services/land-surveying: خدمات الرفع المساحي بمختلف أنواعها.
   - /services/survey-benchmarks: تثبيت الركائز المساحية وتحديد الحدود.

4. **الشفافية والالتزام بالأنظمة:**
   - توضيح واضح ومكتوب بأن الرسوم والمدد تخضع للجهات الحكومية واللوائح السارية.
   - تمييز مسؤوليات العميل والمكتب الهندسي والجهة الحكومية.
   - عدم عرض أرقام تراخيص غير مدققة، مع تخصيص قسم قابل للتفعيل عند اعتماد البيانات الرسمية.
